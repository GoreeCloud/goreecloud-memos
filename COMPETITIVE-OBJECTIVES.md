# GoreeCloud Memos — Competitive Objectives

This record defines the lightweight note and quick-capture products GoreeCloud Memos uses as benchmarks for continuous improvement. Competitive targets are not automatic current-feature claims.

## Primary benchmark products

- Google Keep
- Apple Notes, specifically its fast capture and lightweight everyday-note workflows
- Microsoft OneNote, for selected quick-capture and cross-device usability expectations without adopting its full notebook complexity
- Simplenote
- Memos / usememos, as the maintained-fork upstream foundation and continuing technical reference
- Comparable lightweight, privacy-focused, self-hosted, and cross-device quick-note applications

## Capabilities to match or improve

- Extremely fast note creation and editing
- Compact quick composer with minimal navigation friction
- Markdown-friendly notes and checklists
- Pinning and useful per-note visual differentiation
- Labels/tags and simple filtering
- Fast search
- Archive, restore, recoverable Trash, and safe deletion
- Attachments and inline images without making the product unnecessarily heavy
- Responsive phone, tablet, and desktop web/PWA behavior
- First-party Linux and Android client delivery where it improves access without creating a second data silo
- Portable export in open or documented formats
- Private accounts and private-by-default note visibility
- Reliable backup, recovery, upgrades, rollback, and self-hosted deployment

## Objectives GoreeCloud Memos should exceed

- No advertising, sponsorship, or engagement-driven product behavior
- Self-hosted operation with GoreeCloud-controlled data and infrastructure
- Strong privacy, least privilege, non-root runtime hardening, and explicit publication boundaries
- Portable data and recoverable deletion rather than provider-controlled lock-in
- Reproducible releases, immutable production artifacts, backup coverage, monitoring, rollback, and tested persistence
- One consistent GoreeCloud Memos identity across web, Linux, and Android clients
- Glaze UI consistency and accessibility while retaining a lightweight quick-capture experience
- Clear separation from GoreeCloud Notes so Memos remains fast and focused instead of becoming an overloaded knowledge-management application

## Capabilities intentionally rejected or bounded

- Turning Memos into an Evernote-class or deep knowledge-management workspace
- Nested notebook hierarchies, knowledge graphs, extensive backlinks, heavy research organization, OCR-heavy document processing, or broad revision systems when those belong in GoreeCloud Notes
- A second memo database or independent synchronization layer inside native clients
- Public-by-default or social-discovery workflows as the normal product model
- Required proprietary cloud services, analytics, or AI providers for core quick-note use

## Competitive review rule

A competitor feature should be adopted only when it improves quick capture, retrieval, privacy, security, accessibility, portability, reliability, or cross-device use without undermining Memos' deliberately lightweight role. Features that belong in GoreeCloud Notes should remain there rather than being added merely for feature-count parity.
