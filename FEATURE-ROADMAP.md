# GoreeCloud Memos — Feature Roadmap

**Repository projection:** v0.5  
**Status:** Planned  
**Implementation status:** Partial development only; roadmap completion is not established.

## Governing authority

The authoritative roadmap is `GoreeCloud/Feature Roadmap/GoreeCloud Memos/goreecloud-memos.md` in GoreeCloud Drive. This repository file is a synchronized implementation-facing projection.

## Product direction

GoreeCloud Memos is intended to provide instant capture, simple organization, privacy, portability, offline-capable clients, cross-device synchronization, self-hosting, and tested recovery while remaining deliberately lighter than GoreeCloud Notes.

## Current implementation position

Phase 0 repository audit is established for the current canonical repository, and the first Phase 1 vertical slice now covers local browser capture and persistence. This does **not** establish the broader Memos Core as complete.

## Roadmap sequence

1. Existing implementation audit.
2. Memos core.
3. Search and saved views.
4. Shared synchronization platform.
5. Official web, desktop, and mobile clients.
6. Portability, backup, and tested recovery.
7. Privacy, security, multi-user isolation, Notes handoff, and applicable platform integration.
8. Accessibility, performance, reliability, release evidence, and Stable qualification.

## Release boundary

No roadmap phase is complete merely because documentation or scaffolding exists. Completion requires implementation and authoritative verification evidence.
