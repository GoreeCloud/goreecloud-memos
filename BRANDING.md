# GoreeCloud Memos — Branding

## Product name

Use **GoreeCloud Memos** for the product and `memos` for the canonical repository identifier.

## Product role

GoreeCloud Memos is the quick-capture product. GoreeCloud Notes is the deeper note-taking and knowledge-management product.

## Design principle

**Open → type → done.**

## Interface system

Glaze UI is the governing GoreeCloud interface system. The current Official Anchor producer release is **GLAZE UI V1.6 / 1.6.0**. The web-shell work in this repository targets that current presentation language while remaining a downstream Development consumer: repository-local rendered, accessibility, representative-form-factor, performance, and human visual acceptance are still required before any Glaze conformance, production, or Anchor claim.

The browser experience intentionally uses the previous GoreeCloud Memos information architecture as a product reference—persistent workspace navigation, prominent search, compact quick capture, label navigation, and a card-oriented memo board—while preserving the newer local persistence, search/filter, Saved View, label-management, bulk-label, lifecycle, and presentation-mode capabilities.

## Asset rule

Do not independently redraw or replace the Memos identity in this repository. If the canonical Branding Assets entry changes, update or remove the synchronized consumer derivative through a verified branding reconciliation rather than retaining multiple competing icons.

Branding and Glaze presentation do not create technical authority for privacy, synchronization, security, backup/recovery, production readiness, or application lifecycle claims.
