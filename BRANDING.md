# GoreeCloud Memos — Branding

## Product name

Use **GoreeCloud Memos** for the product and `goreecloud-memos` for the canonical repository identifier.

## Product role

GoreeCloud Memos is the quick-capture product. GoreeCloud Notes is the deeper note-taking and knowledge-management product.

## Design principle

**Open → type → done.**

## Interface system

Glaze UI is the governing GoreeCloud interface system. The current development UI uses simple system-native primitives and accessibility-conscious layout as an implementation scaffold; it has **not** received Glaze UI conformance or visual acceptance.

## Assets

No new canonical product icon or logo is established by this implementation slice. Historical branding material must not be promoted as current authority without verification.
